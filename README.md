## 專案簡介

wvdas 是一款面向手遊《Wizardry Variants Daphne》（巫術 Variants Daphne）的自動掛機指令碼，內建圖形介面，覆蓋日常刷圖、任務洞窟、懸賞、礦石採集、釣魚、戰鬥策略與異常恢復等流程。

與通用型自動化指令碼相比，wvdas 針對本作中常見的 **網路波動、模擬器卡頓、遊戲閃退、畫面卡死、ADB 連線異常** 等情況做了專門處理，並提供任務級與任務點級的獨立配置能力。

指令碼支援簡體中文與英文兩種遊戲介面。

## 功能特性

### 1. 執行穩定性與自動恢復

- **遊戲自動重啟**：檢測到畫面長時間靜止、定位失敗次數超限、寶箱或戰鬥耗時異常、連續點選 Resume 無響應等情況時，自動重啟遊戲。
- **網路異常處理**：自動識別並點選 Retry；遇到返回標題、重新下載等介面時按預設流程恢復。
- **ADB 自動恢復**：ADB 離線、連線超時或裝置丟失時，自動結束並重啟 ADB 服務。
- **模擬器自動恢復**：連續重啟遊戲超過設定次數後，自動重啟模擬器；支援讀取並結束已存在的模擬器程序。
- **啟動前自檢**：啟動時檢查模擬器與 ADB 狀態，必要時自動啟動模擬器並建立連線。
- **卡死檢測**：基於連續截圖差異判斷畫面是否靜止；全黑截圖會被跳過，以降低誤判。
- **異常畫面兜底**：無法識別的介面會嘗試返回、點選安全位置，並在達到最大嘗試次數後重啟遊戲。
- **模擬器路徑校驗**：檢測到疑似錯誤的模擬器路徑時彈窗提示。
- **空氣牆處理**：可選的“重啟後嘗試繞過空氣牆”功能；Resume 連續點選超過 5 次會判定為卡住並重啟。
- **多顯示器相容**：模擬器存在多個顯示埠時，優先使用預設顯示器。

### 2. 任務與地圖系統

- **任務分類瀏覽**：按“最新任務、主線前三章、主線第四章、任務洞窟、FFXI 聯動、礦石、月常、其他、自定義”分類。
- **任務提示**：任務帶有 `_TIPS` 時，選擇任務後強制彈出說明視窗，並在日誌中輸出。
- **任務點系統**：地下城任務可拆分為多個任務點，逐點尋路、逐點執行。
- **樓層檢測**：開啟地圖時校驗當前樓層標題，支援同一樓層的多種標題尺寸；檢測失敗會儲存截圖並自動退出錯誤樓層。
- **地圖尋路**：支援按方向拖動地圖、區域裁剪、目標點二次確認、哈肯/大哈肯搜尋、樓梯與跨樓層移動。
- **自動搜尋**：支援面板上的“自動寶箱”（`chest_auto`）與“自動標記尋路”（`mark_auto`），並在按鈕不可用或路徑不存在時自動退出搜尋。
- **直接退出地下城**：任務可使用 `leaveDung` 直接退出副本；該指令適用性有限，需謹慎配置。
- **時空跳躍**：自動完成詛咒之輪的時間跳躍，並可選擇跳躍目標節點。
- **因果調整**：跳躍前可自動關閉未指定的因果，並按任務配置開啟目標因果。
- **善惡調整**：遇到伏擊/無視事件時，按面板設定的方向自動調整善惡值。
- **自動快進**：識別到對話快進關閉時自動開啟。
- **特殊對話處理**：可識別並處理常見對話選項，包括購買骨頭、屍油等；任務也可配置專屬對話選項與回撥。
- **特殊雜物切換**：開箱時檢測指定雜物，命中後自動切換到另一任務（例如水路船一妖精、要塞八層妖精）。
- **關鍵事件停止**：任務可配置特定圖片作為強制停止條件。

### 3. 戰鬥系統

- **戰鬥策略組**：為每個角色配置技能槽位（左上/右上/左下/右下/防禦）、技能等級（1–7）與執行順序。
- **策略重置**：
  - 每次啟動指令碼、重啟遊戲、角色死亡或再起後自動重置；
  - 可按策略組設定“進入地下城時重置”；
  - 高階選項支援“每場戰鬥開始前重置”；
  - 支援“釋放任一技能即視為本組完成”。
- **全自動戰鬥**：策略為空、角色未匹配或策略名為“全自動戰鬥”時，自動雙擊開啟遊戲內自動戰鬥。
- **自動戰鬥狀態檢測**：識別自動戰鬥按鈕的啟用/禁用狀態，必要時自動開啟。
- **二倍速**：進入戰鬥後自動嘗試開啟二倍速。
- **技能等級降級**：SP/MP 不足導致目標等級技能無法釋放時，自動改用 1 級技能重試。
- **單體目標選擇**：透過方向場卷積識別敵方指示箭頭（灰度與 R 通道分別檢測），優先點選箭頭附近目標；未識別到箭頭時在敵方區域隨機點選。
- **輔助技能**：支援輔助技能釋放；目標可由策略配置指定。
- **復活與再起**：自動處理隊友陣亡、多人陣亡與再起介面；再起後自動執行恢復。
- **任務點級策略**：可為同一任務的每個任務點指定不同的戰鬥策略，任務點完成後自動切換。

### 4. 探索、開箱與恢復

- **快速開箱**：跳過額外檢測，指定開箱角色後快速連續點選開鎖。
- **開箱人選**：支援隨機或固定位置角色；指定角色恐懼/石化時自動改用其他角色。
- **自動恢復**：可分別配置戰鬥後、開箱後、進入地下城時與住宿後首次進本的恢復；角色復活後會強制執行一次恢復。
- **旅店休息**：支援按“完成 N 次地下城後休息”的間隔設定；未發生戰鬥或寶箱、關閉休息、或未達到間隔時自動跳過。
- **豪華房**：可選住宿時優先選擇豪華房。
- **定時重置隊伍**：可設定每 1–12 小時重新召集酒館隊伍，用於清理揹包與調整站位。
- **地下城完成統計**：記錄完成次數、總用時、上次用時、開箱次數與平均耗時、戰鬥次數與平均耗時。

### 5. “0 火”後的資源迴圈

當檢測到“再起之火”耗盡時，指令碼可按面板設定自動切換任務，優先順序如下：

1. **挖礦**：切換到 FFXI 挖礦任務；
2. **刷錢**：切換到“7000G”任務；
3. **釣魚**：切換到釣魚任務。

若三項均未啟用，指令碼會等待約 2 小時後重啟遊戲，以重新點火。

- **釣魚**：
  - 透過方向場卷積與模板匹配檢測魚漂，檢測不到魚漂時拉桿；
  - 自動檢查魚餌餘量，耗盡時回城從倉庫補充並返回釣點；
  - **不會購買魚餌**，僅使用倉庫中已有的魚餌；
  - 統計魚的大小（小/普通/大）與種類（鱸魚、雅羅、鯰魚、鱒魚、鰻魚、三文魚、雜魚等），未收錄魚類會儲存截圖；
  - 每次成功釣魚儲存截圖；
  - 當前提供“近端釣魚”任務，可從主城或釣魚介面啟動。
- **FFXI 挖礦**：
  - 自動前往標記礦點、連續挖掘、識別產出；
  - 統計全改、下改、銜尾蛇、精煉石、改造石、銀礦石、特級/上級/中級/下級礦石等數量；
  - 挖到“全改”時自動截圖；
  - 鶴嘴鋤耗盡時退出副本、回城並重新召集 `FFXIStone` 隊伍補充。
- **刷錢**：自動完成“7000G”時間跳躍、返回要塞、前往王城、領取與提交任務。

### 6. 日常 / 周常輔助

- **官網領取 50 鑽**：提供新舊官網入口，按周判斷並在需要時高亮提醒。
- **靈廟重新整理提醒**：按雙週週期判斷，提供“靈廟已重新整理”一鍵切換到靈廟任務。
- **月常任務分類**：爐壺靈廟、戰士靈廟、鋼試煉、蠍女懸賞等。

### 7. 資料統計與日誌

- 介面摘要區實時顯示：
  - 已完成地下城次數、總用時、上次用時；
  - 箱子效率（秒/箱）、累計開箱次數、平均開箱耗時；
  - 累計戰鬥次數、平均戰鬥用時；
  - 釣魚與挖礦的專項統計；
  - 重要事件（角色死亡、再起、善惡變化、購買骨頭/屍油、任務切換等）。
- 日誌按天輪轉，預設保留 3 天；截圖與日誌會定期清理。
- 重啟前截圖、樓層檢測失敗截圖、釣魚成功截圖、挖礦特殊產出截圖等均儲存在 `logs` 目錄。

### 8. 自定義與本地化

- **自定義任務**：透過 `mod/quest.json` 新增任務，支援自定義任務點、進入路線、回城路線、樓層檢測、提示、特殊對話與特殊雜物回撥；與內建任務代號衝突時會自動改名。
- **自定義圖片**：可放置於 `mod/images/` 或 `mod/` 下，作為內建圖片缺失時的補充。
- **介面語言與遊戲語言分離**：指令碼介面語言與遊戲內語言可分別設定為 `zh_CN` 或 `en_US`。
- **自動更新**：定期檢查 GitHub Releases；發現新版本後可自動下載（帶進度條）或手動下載，更新完成後自動重啟。版本變更時會彈出更新日誌。

## 安裝與啟動

### 1. 安裝模擬器與遊戲

1. 下載並安裝 MuMu 模擬器。
2. 安裝遊戲 APK。
3. 首次啟動如遇黑屏，請安裝 Google 三件套；MuMu 桌面通常提供一鍵安裝入口。
4. 如遇 Google 登入彈窗，連續按返回鍵即可。
5. 如遇“違反安全策略”，請關閉 Root。
6. 如遇 `unable to initialize the unity engine graphics API`，先切換 DirectX 啟動，再切回 Vulkan 啟動。
7. 在模擬器設定中開啟 **ADB 除錯**。
8. 將解析度設定為 **1600 × 900，240 DPI**。
9. 關閉模擬器的 **網路橋接模式**。

### 2. 模擬器路徑與 ADB 地址

在指令碼“模擬器”分組中設定：

| 模擬器 | 可執行檔案路徑 |
| --- | --- |
| MuMu 15 | `Netease\MuMu\nx_device\15.0\shell\MuMuNxDevice.exe` |
| MuMuX | `Netease\MuMu\nx_device\12.0\shell\MuMuNxDevice.exe` |
| MuMu 12 | `Netease\MuMu Player 12\shell\MuMuPlayer.exe` |

- **ADB 地址**預設為 `127.0.0.1:16384`。少數情況下埠可能為 `5555`，也可從多開管理器中查詢。
- 輸入純埠號（如 `16384`）或 `5555,16384` 時，指令碼會自動補全為 `127.0.0.1:16384`；也支援直接填寫完整地址。
- **模擬器編號**用於多開場景，指定需要連線的第幾個模擬器例項。
- 多開時建議關閉目標模擬器，讓指令碼自行啟動，以免重啟模擬器時影響全部例項。

### 3. 遊戲內設定

為保證影象識別穩定性，建議按以下方式設定遊戲：

- 畫面質量：**中（速度優先）**。
- 幀率：**30 FPS**。
- 地下城亮度：**最暗至 25% 亮度**之間。
- 自動恢復：勾選“使用技能驅散異常狀態”。
- 揹包補充：
  - 勾選“將非補充物件的道具存入倉庫”；
  - 勾選“與旅店住宿時自動補充”；
  - 如補充按鈕不可用，可勾選“持有 1 個哈肯的鉤爪”。
- 自動移動：一般關閉“優先不推進任務的路線”；刷礦石 plus 等特殊地圖時按要求開啟。
- 地圖縮放：**保持未縮放**。未縮放的地圖約為 17 個格子；如已縮放，建議重灌遊戲。
- 計劃使用的技能必須放入**快捷欄**。
- **關閉對話自動選擇分支**。部分任務（如 7000G 與特殊對話任務）依賴指令碼自行選擇對話。
- 地下城中展開地圖下方的**快捷按鈕欄**。
- 有時間跳躍內容的任務，建議先手動完成一次或全程觀察首次執行，避免特殊劇情導致流程中斷。
- 遊戲地圖必須**探明所有區域**；使用目標點判定的地圖，至少需要探明目標區域。
- 建議提前解鎖目標地圖對應的大哈肯。
- 若角色進入副本後無法移動，通常是網路問題，請更換加速器。

### 4. 啟動指令碼

**圖形介面模式：**

1. 雙擊 `wvd.exe`，或執行 `python src/main.py`。
2. 在“模擬器”分組設定路徑與 ADB 地址。
3. 在“目標”分組選擇任務類別與任務。
4. 根據任務需要調整“探索”“戰鬥”“高階”等設定。
5. 點選“指令碼，啟動！”。

**無頭模式：**

建立 `wvd.exe` 的快捷方式，在“目標”一欄末尾新增：

```text
-headless
```

命令列同時接受 `-config <路徑>` 引數。當前版本的無頭模式從工作目錄讀取 `config.json`；如需使用其他配置，請先將其設為工作目錄下的 `config.json`。

無頭模式會直接讀取配置並啟動任務，日誌輸出到控制檯與 `logs` 目錄。

### 5. 配置檔案

- 配置檔案為工作目錄下的 `config.json`，由圖形介面自動儲存。
- 每個任務可啟用“用任務定製的配置檔案覆蓋預設配置”，獨立儲存探索、戰鬥與高階設定。
- 如配置異常導致無法啟動，可備份後刪除 `config.json`，讓指令碼重新生成預設配置。

## 指令碼配置說明

### 模擬器

| 設定項 | 說明 |
| --- | --- |
| 模擬器路徑 | 指向 MuMu 模擬器可執行檔案；路徑異常時會彈窗提示 |
| ADB 地址 | 預設 `127.0.0.1:16384`，支援完整地址與自動補全 |
| 模擬器編號 | 多開時指定模擬器例項序號 |
| 本指令碼的語言 | 介面語言：`zh_CN` / `en_US`，修改後需重啟指令碼 |
| 遊戲內的語言 | 遊戲介面語言：`zh_CN` / `en_US`，必須與模擬器內遊戲一致 |

### 目標

| 設定項 | 說明 |
| --- | --- |
| 任務類別 | 按分類篩選任務 |
| 任務目標 | 選擇具體任務 |
| 任務定製配置 | 為當前任務單獨儲存一套配置；“清除”可刪除該任務的定製配置 |

選擇任務後，若任務帶有提示，會彈出任務說明視窗。

### 探索

| 設定項 | 說明 |
| --- | --- |
| 開箱人選 | 隨機，或固定為左上/中上/右上/左下/中下/右下 |
| 快速開箱 | 不進行額外檢測，快速連續開鎖；需要足夠開鎖能力 |
| 在戰鬥結束後進行恢復 | 戰鬥結束後執行自動恢復 |
| 在開箱後進行恢復 | 開箱結束後執行自動恢復 |
| 在進入地下城時進行恢復 | 每次進入地下城時恢復一次 |
| 在住宿後首次進入地下城時進行恢復 | 住宿後的首次進本恢復 |
| 啟用旅店休息 | 關閉後跳過旅店休息 |
| 完成 N 次後休息 | 每完成 N 次地下城休息一次 |
| 善惡 | 設定善惡調整方向，並顯示剩餘調整點數 |
| 啟用定時重置隊伍 | 每 1–12 小時重新召集酒館隊伍 |

**回城與休息判定：**

- 未發生戰鬥或寶箱時跳過住宿；
- 關閉“啟用旅店休息”時跳過住宿；
- 未達到休息間隔時跳過住宿；
- 啟用定時重置隊伍時，達到時間間隔後會回城重置隊伍。

### 戰鬥

| 設定項 | 說明 |
| --- | --- |
| 全程策略 | 整個任務使用同一套戰鬥策略 |
| 自定義任務點策略 | 為每個任務點分別指定策略；需要啟用任務定製配置 |
| 戰鬥方案 | 管理角色技能組、重置規則與完成規則 |

### 戰鬥方案

戰鬥方案由若干“策略組”組成，每組包含：

- **策略組名稱**；
- **角色**；
- **技能槽位**：左上技能、右上技能、左下技能、右下技能、防禦；
- **技能等級**：1–7；
- **進入地下城時重置**；
- **[高階] 戰鬥開始前重置**；
- **[高階] 釋放任一即視為完成**。

執行規則：

1. 指令碼按策略組中的順序匹配當前行動角色。
2. 命中後釋放對應技能，並將該條目從當前策略佇列中移除。
3. 若開啟了“釋放任一即視為完成”，釋放任一技能後清空當前策略。
4. 角色不在策略中、策略為空或策略名為“全自動戰鬥”時，執行遊戲內自動戰鬥（雙擊自動）。

> 遊戲會在角色死亡或遊戲重啟後丟失“重複上一次”狀態，因此指令碼會在這些時點自動重置策略。  
> 開啟“每場戰鬥開始前重置”前，請確認你理解遊戲內“重複上一次”的行為。

示例：
- 我想讓柚子復讀千紫萬紅 3： 
  戰鬥方案寫一條“柚子，千紫萬紅，3”；遊戲內設定柚子的自動方案為“重複上一次”。 
- 我想讓葉卡每場戰鬥僅釋放一次 AOE，並在之後進行自動攻擊： 
  戰鬥方案寫一條“葉卡，AOE，1”；指令碼設定開啟“每場戰鬥重置”；遊戲內設定葉卡的自動方案為“攻擊”。 
  指令碼釋放一次葉卡 AOE 後，策略為空，此時執行遊戲內的自動方案；遊戲內的自動方案為攻擊，那麼葉卡會持續攻擊。 
- 我想讓面具人進行動靜裂地迴圈： 
  戰鬥方案寫 2*n 條：第一條“面具，動靜，1”；第二條“面具，裂地，1”；然後按照你的喜好重複若干次。

### 要塞八層妖精

- 指令碼會自動完成三次沙人緣互動，完成後進行時間跳躍並結算。

- 該任務會強制關閉“定時重置隊伍”和“繞過空氣牆”。

### 鋼試煉

- 任務分類為“月常”，用於完成每週/活動任務的委託部分。
- 請打上兩個標記：一個標記最終 Boss，一個標記左路物理路線。
- 使用 `mark_auto` 加速流程。

### FFXI 挖礦

請按以下步驟準備：

1. 購買 9999 個鶴嘴鋤並儲存在倉庫。
2. 六人隊伍脫掉所有裝備，儘可能多地攜帶鶴嘴鋤。
3. 在王城工會新建隊伍並命名為 `FFXIStone`。
4. 前往活動地圖 2F，在哈肯正對的礦點前打上標記。
5. 確保這是該層唯一的標記。
6. 在副本內或主城啟動指令碼。

補充說明：

- 鶴嘴鋤耗盡後，指令碼會退出副本、回城並重新召集 `FFXIStone` 隊伍。
- 若在樓層選擇處卡住，請嘗試開啟所有哈肯。
- 挖到“全改”時會自動截圖。

### 釣魚

- 當前提供近端釣魚任務，可從主城或釣魚介面啟動。
- 支援回城補充魚餌，但**只會使用倉庫中已有的魚餌，不會購買**。
- 魚餌耗盡時自動回城補充並返回釣點。
- 自動統計魚類大小與種類；未收錄魚類與每次成功釣魚都會儲存截圖。
- 0 火耗盡時可自動從第四章“美麗礦石的真相”節點繼續。

### 懸賞：蠍女

- 推薦刷 7 級懸賞蠍女。
- 前排約 180 閃避即可基本避免被命中；後排不會被連續針對。
- 參考陣容（不釋放攻擊技能）：
  - 前排：堆疊 180 閃避的牧師，以及任意角色（推薦忍者）；
  - 後排：正常堆攻擊的長槍/弓箭戰士，或堆攻擊的苦無忍者。
- 裝備足夠時可使用“蠍女 + 風暴六手”連刷任務。

- 用於刷取暗抗裝備與小號經驗。

- 開箱難度較高，推薦盜賊主角或專門培養的開箱角色。

- 變種站位：牧師面具左上、戰士艾莉賽中上、戰士王女右上、牧師葉卡中下。

## 自定義任務

指令碼會在啟動時讀取 `mod/quest.json`，並與內建任務列表合併。自定義任務在中文介面歸入“自定義”分類，在英文介面歸入“Custom Requests”。

### 目錄結構

```text
專案根目錄/
├─ mod/
│  ├─ quest.json
│  ├─ images/
│  │  └─ 自定義圖片.png
│  └─ 自定義圖片.png
├─ wvd.exe
└─ ...
```

- 自定義圖片可放在 `mod/images/` 或 `mod/` 下。
- 自定義任務與內建任務內部代號衝突時，會自動追加 `_mod` 字尾。
- 同時提供中英文任務名時優先使用當前介面語言；只提供一種時會自動補齊另一種。

### 最小示例

```json
{
  "MyQuest": {
    "_TYPE": "dungeon",
    "questName": "[自定義]示例任務",
    "questName_en_US": "[Custom] Example",
    "_FloorCheck": "stair_DH_R4",
    "_TARGETINFOLIST": [
      ["position", "右下", [500, 600]],
      ["chest_auto"],
      ["harken", "左上", null]
    ],
    "_EOT": [
      ["press", "DH", ["EdgeOfTown", [1, 1]], 1],
      ["press", "DH-R4", "input swipe 650 250 650 900", 1]
    ],
    "_RTT": ["City_DHI", "input swipe 54 1346 302 1571", [500, 1100]],
    "_TIPS": "這是一個示例任務。"
  }
}
```

### 任務欄位

| 欄位 | 必填 | 說明 |
| --- | --- | --- |
| `_TYPE` | 是 | `dungeon` 或 `quest` |
| `questName` | 至少一項 | 中文任務名 |
| `questName_en_US` | 至少一項 | 英文任務名 |
| `questCategory` | 否 | 自定義任務會統一歸入“自定義” |
| `questCategory_en_US` | 否 | 自定義任務會統一歸入“Custom Requests” |
| `_TARGETINFOLIST` | 地下城任務必填 | 任務點列表 |
| `_EOT` | 地下城任務通常需要 | 從城鎮進入地下城的流程 |
| `_RTT` | 否 | 從地下城返回城鎮的流程 |
| `_preEOTcheck` | 否 | 進本前需要先點選的介面 |
| `_FloorCheck` | 否 | 樓層檢測模板名，可為字串或列表 |
| `_TIPS` | 否 | 任務提示，選擇任務時彈窗顯示 |
| `_SPECIALDIALOGOPTION` | 否 | 特殊對話選項圖片列表 |
| `_SPECIALFORCESTOPINGSYMBOL` | 否 | 出現即停止任務的圖片列表 |
| `_SPECIALJUNK` | 否 | 開箱時要檢測的特殊雜物圖片 |
| `_SPECIALJUNK_CALLBACK` | 否 | 檢測到特殊雜物後切換的目標任務代號 |

### 任務點格式

```json
["目標型別", "拖動方向或 swipe 指令", "檢測區域或座標"]
```

**目標型別：**

| 目標型別 | 說明 |
| --- | --- |
| `position` | 前往指定座標；第三個引數為 `[x, y]` |
| `chest` | 搜尋寶箱；檢測區域可省略，指令碼會自動排除地圖邊緣 |
| `chest_auto` | 使用面板“自動寶箱”按鈕 |
| `mark_auto` | 使用面板“自動標記尋路”按鈕 |
| `harken` / `Bharken` | 搜尋哈肯/大哈肯；第三個引數可填 `stair_xxx` 以校驗樓層 |
| `stair_xxx` | 搜尋樓梯或樓層入口 |
| `leaveDung` | 直接退出地下城 |
| `stay` | 原地等待約 2 秒 |
| 自定義圖片名 | 搜尋對應圖片 |

**拖動方向：**

- `左上`、`右上`、`左下`、`右下`；
- `null`：按預設順序向多個方向搜尋；
- 也可直接填寫 `input swipe x1 y1 x2 y2`。

**檢測區域：**

- 多個矩形：`[[x, y, w, h], ...]`；
- `position` 可填 `"default"`，使用內建預設區域；
- `null`：使用預設區域。

### 進入與回城流程

`_EOT` 中每一項的格式為：

```json
["press", "目標圖片", "找不到時的兜底動作", 重試間隔]
```

- 兜底動作可以是圖片名、座標、`"return"` 或 `input swipe ...`；
- 最後一項也可以使用 `["press", "intoWorldMap", ["目標", "swipe 指令", [x, y]]]` 的形式透過世界地圖進入。

`_RTT` 的格式為：

```json
["城市圖片名", "拖動指令", [任意鍵點選位置]]
```

### 特殊雜物與任務切換

- `_SPECIALJUNK` 用於在開箱時檢測指定雜物；
- 命中後可透過 `_SPECIALJUNK_CALLBACK` 切換到另一任務；
- 啟用該功能的任務會禁用快速開箱與正常開箱的多次點選，以避免過早關閉寶箱介面；
- 該檢測仍可能存在漏報，請以任務說明為準。

### 特殊對話

- `_SPECIALDIALOGOPTION` 中的圖片一旦被識別，指令碼會點選對應選項並關閉角色介面；
- 任務可在程式碼層配置回撥，以執行額外邏輯；
- 適用於需要選擇特定分支、購買特定物品或避免卡對話的場景。

## 從原始碼構建

### 執行環境

- Windows 10 / 11
- Python 3.10

### 安裝依賴

```bash
pip install -r requirements.txt
```

### 編譯本地化檔案

```bash
python -m babel.messages.frontend compile -d locale -D messages
```

### 從原始碼執行

```bash
python src/main.py
```

### 打包為可執行檔案

可以使用專案根目錄下的：

```text
用於本地測試的打包指令碼.bat
```

該指令碼會建立 `.venv`、安裝依賴、編譯本地化檔案，並使用 PyInstaller 生成 `dist/wvd/`。

也可以手動執行：

```bash
pyinstaller --onedir ^
  --paths=src ^
  --collect-submodules=ppadb ^
  --add-data "resources;resources/" ^
  --add-data "locale;locale/" ^
  src/main.py -n wvd
```

### 自動釋出

推送至 `master` 分支後，GitHub Actions 會：

1. 從 `src/main.py` 讀取版本號；
2. 編譯本地化檔案；
3. 使用 PyInstaller 構建；
4. 打包並生成 MD5；
5. 建立 GitHub Release；
6. 正式版本會更新 GitHub Pages 上的 `release.json`。

版本號格式為語義化版本；帶 `-` 的版本會被標記為預釋出。

### 清理構建產物

```text
清理本地打包結果.bat
```

用於刪除 `dist/`、`build/`、`*.spec` 與 `__pycache__`。

## 注意事項與已知限制

1. **解析度固定**：指令碼影象識別基於 1600 × 900、240 DPI，其他解析度可能導致識別失敗。
2. **語言必須一致**：指令碼中的“遊戲內的語言”必須與模擬器內遊戲語言一致。
3. **地圖必須探索**：大多數任務要求目標區域地圖已探明；使用自動寶箱或標記尋路時尤其重要。
4. **標記專用**：使用 `mark_auto` 的任務通常要求目標樓層無其他自定義標記。
5. **時間跳躍任務先手動驗證**：首次執行建議觀察，避免特殊劇情、工會彈窗或懸賞提示導致流程中斷。
6. **關閉對話自動選擇**：部分任務依賴指令碼自行選擇分支。
7. **“每場戰鬥重置”屬於高階功能**：請先理解遊戲內“重複上一次”的機制。
8. **多開模擬器**：目標模擬器未執行時，建議讓指令碼自行啟動；同時存在多個模擬器時，重啟模擬器可能影響全部例項。
10. **釣魚不購買魚餌**：指令碼只使用倉庫中已有的魚餌。
11. **部分中文資源仍在完善**：如遇到識別失敗，請保留日誌與截圖反饋。
12. **使用風險自負**：請遵守遊戲使用者協議與相關法律法規，自行評估自動化工具的使用風險。

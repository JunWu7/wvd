# wvdas - 巫術daphne的自動掛機腳本
[English (v1.8.20)](README.en.md)

一個自帶gui的巫術手遊的刷怪腳本.
現已進行了2.0版本的更新!

和其他流行的遊戲自動腳本相比, 針對巫術手遊具有的 ***複雜的網路環境*** 和 ***偶爾的效能波動*** 做了專門的特殊最佳化.

## wvdas具有哪些普通腳本做不到的功能?
### 自動重啟
遊戲閃退? 立刻重啟!

網路故障? 秒點"重試". 一直卡頓? 重啟遊戲!

卡在寶箱裡, 卡在門裡, 卡在戰鬥中, 卡在開箱子流程裡, wvdas都能透過檢測"靜止的畫面"或者"過長的耗時"來自動重啟遊戲.

### "0火轉要錢"
一覺醒來發現"再起之火"耗盡了, 遊戲停在詛咒之輪, 時間都浪費了怎麼辦?

wvdas可以再檢測到"再起之火"耗盡後, 立刻將任務變更為"找公主要錢".

最大化提高掛機效率~ _(當然, 你也可以關掉這個功能)_

### 自定義戰鬥策略
想要進行復雜的戰鬥策略? 先要先防禦兩個回合然後復讀居合?

2.0版本加入了"自定義戰鬥策略", 你可以盡情配置獨屬於你的陣容的戰鬥策略!

### 不同任務的獨立配置
想要對每個任務使用不同的配置? 在低難任務選擇快速開箱和全自動, 在高難任務選擇按任務點的具體戰鬥策略?

現已加入每個任務可以獨立設定, 一鍵從預設切換到任務專屬設定!

## 如何安裝模擬器並設定模擬器和遊戲?
### 模擬器設定
*藍疊不再維護, 請不要再使用藍疊模擬器了.*
- 下載mumu模擬器, mumu12或者mumuX都可以.
- 安裝遊戲apk.
- 初次載入遇到黑屏, 請安裝谷歌三件套. mumu桌面上就有可以直接安裝.
- 如果遇到google登入彈窗, 連續按返回即可.
- 如果遇到"違反安全策略", 關閉root.
- 如果遇到"unable to initialize the unity engine graphics API", 先改成DirectX啟動, 然後再用vulkan啟動就能正常遊戲了.
- 模擬器已經**允許adb除錯**.
- 模擬器解析度為**1600x900**, 240 dpi.

### 腳本的"模擬器"模組設定
- 腳本左上角的"模擬器路徑"為:
	 - MuMu12: Netease\MuMu Player 12\shell\MuMuPlayer.exe
	 - MuMuX: Netease\MuMu\nx_device\12.0\shell\MuMuNxDevice.exe
- 埠號預設為16384. 很罕見的情況下, 可能為5555. 如果兩者皆非, 你可從多開管理器裡找到具體的模擬器埠.
- 關閉**網路橋接模式**.

### 無頭模式
可以用無頭模式來啟動Wvd!

建立wvd.exe的快捷方式, 並在"目標"一欄的末尾加上" -headless"即可啟動無頭模式.

還可以使用"-config 路徑"來指定特定的config檔案.

### 遊戲整體設定
- 遊戲為**英文版**.
- 畫面設定為**中(速度優先)**.
- 調整畫面為**30幀**, 地下城亮度為**最暗-25%亮度**.
- 在自動恢復介面, 勾選了"使用技能驅散異常狀態".
- 在揹包補充介面, 勾選了"將非補充物件的道具存入倉庫Place all non-refill items in storage"和"與旅店住宿時自動補充 Automatically refill when staying at the inn.". (如果無法確認, 勾選"持有1個哈肯的鉤爪Carry 1 Hook of Harken").
- 在自動移動設定中, **關閉"優先不推進任務的路線(Prioritize routes that avoid advancing the request)"**. 但是, 如果你想要刷某些特殊地圖, 則推薦開啟. 開啟後, 會避開揀骨人, 因此請及時關閉. 
- 遊戲地圖**沒有縮放**. 如已經進行了縮放, 推薦重新安裝遊戲. (未縮放過的遊戲地圖應為17個格子左右.)
- 計劃使用的技能**必須放快捷欄**.
- **關閉對話自動選擇分支**. 目前皇女要錢和角鷲都是基於不自動選擇分支做的.
- 有時間跳躍內容的任務, **務必先手動進行一次(或在一旁盯著看第一次)**, 以避免某些特殊任務的觸發導致腳本卡死. 例如: 要塞6f哈肯沒法尋路, 王城的工會彈出要錢任務, 懸賞介面的更新提示等等.
- 在地下城中, **展開地圖下方的快捷按鈕欄**. 

### 關卡內部設定
- 遊戲地圖必須**探明所有區域**. 對於部分進行目標點判定的地圖, 至少要探明目標區域的全部地圖.
- 遊戲內最好已經解鎖了目標地圖所屬的大哈肯.
- 如果出現人物一進副本就卡住無法移動, 這是由於網路問題引起的, 請更換加速器.

## 如何對具體任務進行腳本配置?
### 探索設定
- "開箱人選: 隨機"會隨機指定人物.
- 如果指定了固定開箱角色, 那麼在恐懼或石化後會改為其他隨機角色.
- 關閉"啟用旅店休息"後, 在刷圖地下城和部分任務地下城將永久跳過旅店休息.
- 旅店休息間隔指完成了多少次地下城後進行休息. 1代表完成一次休息一次, 以此類推. 
- "戰鬥後恢復"和"開啟寶箱後恢復"是指在這兩個動作後執行的自動恢復操作. 如果恢復沒有驅散異常, 檢查遊戲設定, 角色技能以及角色異常狀態.
### 戰鬥設定
- 你可以設定全程(整個任務)使用某個特定的戰鬥方案.
- 你也可以設定使用"自定義任務點策略". 該選項會強制開啟"任務定製的配置檔案", 並同時列出該任務包含的所有任務點.
- 你可以對前往某個任務點的過程中設定不同的戰鬥策略.
	- 例如, 第一個點在boss面前, 第二個點在boss位置.
 	- 你可以在第一個任務點前使用"道中策略", 在第二個任務點使用"boss策略".
 
### 戰鬥方案
- **戰鬥方案**已經修改.
- 戰鬥方案是一系列具有特定順序的動作, 腳本會按照出現情況和優先順序依次執行.
- 由於遊戲會在死亡或重啟後丟失角色的上一次行動, 會導致**遊戲內設定**"重複上一次"失效, 因此會在每次死亡或重啟遊戲後重置戰鬥方案.
- 如果角色在戰鬥方案裡, 那麼會按照方案的設定釋放技能且暫時刪除這一條目. 如果角色不在方案裡, 那麼會雙擊自動, 此時遵循遊戲內對該角色的自動戰鬥方案.
- 下面是具體的例子:
	- 我想讓柚子復讀千紫萬紅3:
		- **戰鬥方案**寫一條"柚子, 千紫萬紅, 3", **遊戲內設定**柚子的自動方案為"重複上一次".
	- 我想讓葉卡每場戰鬥僅釋放一次aoe, 並在之後進行自動攻擊:
 		- **戰鬥方案**寫一條"葉卡, aoe, 1", **腳本設定**開啟"每場戰鬥重置". **遊戲內設定**葉卡的自動方案為"攻擊".
   		- 腳本釋放一次葉卡aoe後, 策略為空, 此時執行遊戲內的自動方案, 遊戲內的自動方案為攻擊, 那麼葉卡會持續攻擊.
	- 我想讓面具人進行動靜裂地迴圈:
 		- **戰鬥方案**寫2*n條, 第一條"面具, 動靜, 1". 第二條"面具, 裂地, 1", 然後按照你的喜好重複若干次.

## 如何對具體任務進行遊戲陣容配置?
### 礦石洞: 
- 礦石洞具有兩種模式:
	- 不含plus的模式: 在特定區域裡進行搜尋.
	- 含plus的模式: 要求點亮所有可能出現的地圖. 會進行自動寶箱搜尋, 然後前往關底boss處退出副本.
 	- 由於plus模式具有某些陷阱房, 因此請**勾選"優先不推進任務的路線(Prioritize routes that avoid advancing the request)"**
### 懸賞
- 目前支援三個懸賞任務: 吉爾, 蠍女, 以及蠍女+風暴六手.
- 吉爾是前期過度用的任務, 不推薦長期刷去.
- 吉爾任務需要roll地圖. 可以透過跳躍到"甦醒"然後跳躍到第二章或更加未來來重新整理地圖.
- 推薦刷蠍女. 前排180閃避就幾乎不會被蠍女命中, 後排也不會連續被扎, 因此只需要牧師開啟"使用本職業技能"即可完成掛機.
- 參考陣容-不釋放攻擊技能:
  - 前排: 堆疊180閃避, 牧師以及任意角色(推薦忍者). 沒有攻擊或神力等其他任何要求.
  - 後排: 正常堆攻擊的長槍/弓箭戰士, 或者堆攻擊的苦無忍者.
- 如果你裝備足夠, 也可以進行蠍女+風暴六手的連刷任務.
### 死神暗燈
- 該任務旨在刷去暗抗裝備和小號經驗.
- 由於怪物攻擊較高, 請保證每人都持有光屬性武器(或若干先驅斬)後再進行嘗試.
- 在死神地圖的左上角和門互動後接取任務, 然後清理一個暗燈周圍的所有遊蕩的怪物.
- 面朝暗燈後開啟腳本.
### 要塞7f刷巨人
- 從要塞出發, 擊殺7f門口的那隻巨人.
- 由於版本更新, 現在總是會擊殺燈怪.

### 離別洞窟 / 約定之劍:
- 該洞窟的開箱難度較高, 推薦盜賊主角或者專門培養的開箱工具人.
- 克拉麗莎可以大幅度簡化這個洞窟的戰鬥. 透過將其放置在前排中央, 你可以很好的抵抗魅魔的魅惑. 可以使用全部自動戰鬥.
- 否則, 推薦1速aoe輸出來秒殺魅魔, 速度>90, 魔力>450, 還需要後排配愛麗絲+前排光環工具人來補充20%傷害.
- 該洞窟有大量戰鬥, 推薦攜帶2組aoe+增傷的組合. 也可以僅攜帶1組再攜帶2個小號.
- 參考aoe+增傷的組合:
	  夏莉莉+米拉娜(續航優秀, 可開鎖) > 葉卡+艾莉賽(可以防止偷襲同時單光環足矣, 但續航不足) > 亞當+黛博拉(可開鎖, 但續航不足) > 亞當+阿貝(先驅斬浪費時間而且無效傷害, 續航不足, 不推薦)

### 三牛任務:
- 從時空跳躍啟動, 目標點為"擊敗吾等榮光", 請確保擊殺了人偶. 注意第一次跳人偶可能無法點亮哈肯, 需要手動操作.
- 基本流程為: 跳躍-左上角一牛-**回家休息(可選)**-右邊兩牛-跳躍. 要想關閉途中的回家休息, 請關閉"**啟用旅店休息**".
- 低配陣容推薦: 4人隊伍.
 	- 2戰士, 160+迴避, 300+攻擊, +20冥鋼武器(或角鷲之劍), 只釋放全力一擊.
	- 1牧師, 速度最慢, 閃避能堆多高堆多高, **站前排**, 只是放卡恩停歐斯.
 	- 1法師/1牧師, 速度最快, 魔力能堆多高堆多高, **站牧師後面**, 釋放LA系魔法或秘術.
	- 技能啟用: 關閉系統自動戰鬥, 勾選"群體控制","強力單體"以及"全體AOE".
	- 推薦勾選'跳過**開箱**後恢復', "啟用旅店休息".
    - 三牛的威脅之處在於它可以造成前後換位以及石化呼吸. 高閃避的牧師可以剋制換位, 而沒有後排只有前排的構築同樣可以剋制換位. 至於石化呼吸, 正好交給堆閃避的牧師來控制.
	- 參考陣容: 戰士面具左上, 牧師葉卡中上, 戰士王女右上, 睡法中下.
	- 變種陣容: 牧師面具左上, 戰士艾莉賽中上, 戰士王女右上, 牧師葉卡中下.
		- 利用牧師葉卡的秘術來充當法師的AOE, 有艾莉賽光環, 傷害充足.
		- 艾莉賽站葉卡前面, 需要堆閃避. 但是因為雙光環, 傷害充足.
### 沙影洞:
- 該任務的休息旅店為要塞, 請確保要塞可見.
- 不推薦在沒有完成2周目的情況下使用腳本.
- 注意該任務需要**通關2周目且獲得解除陷阱的知識**. 在完成了2周目後, 從boss房間處獲取知識以瞭解如何關閉陷阱.
- 注意, **1f地圖左右下角的隱藏區域極其容易被遺漏**, 請訪問gamerch以確認解鎖了全部地圖: [攻略](https://gamerch.com/wizardry-daphne/928695),以及 [地圖](https://cdn.gamerch.com/resize/eyJidWNrZXQiOiJnYW1lcmNoLWltZy1jb250ZW50cyIsImtleSI6Indpa2lcLzQ3MTRcL2VudHJ5XC9DVGJLWWRESy5qcGciLCJlZGl0cyI6eyJ0b0Zvcm1hdCI6IndlYnAiLCJqcGVnIjp7InF1YWxpdHkiOjg1fX19)
- 目前提供了三個版本:
   	- 1F回溯刷金箱. 流程為 回溯->雙忍者->三個金箱子->其他箱子. .
   	- 刷怪. 能穿過7個怪物的路線, 平均一次副本能觸發5次左右戰鬥.
   	- 全拿. 在刷怪的基礎上, 還會額外搜尋地圖上的箱子.
### 貿易水路-船艙2層:
- 確保船1上半部分的地圖全部點亮, 船2上半部分的地圖全部點亮.

### "角鷲之劍"任務: 
- 面板**僅能控制最後的boss戰**, 路上小怪為**強制自動戰鬥**. 流程中不包含回城, 所以量力而行.
- 請確保某些地圖中某些區域的全部開啟.
- 開第三層的哈肯有一定機率失敗, 並導致角色死亡.*(暫時不會修復!)*
